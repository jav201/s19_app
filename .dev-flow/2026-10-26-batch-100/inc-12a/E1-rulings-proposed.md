# Inc 12a — E1 questions for the orchestrator

`E1-requirements-draft.md` already follows every recommendation below. A different ruling changes only the ids each row names. Rules applied throughout: prefer removing a feature over guarding it; stay within the PLAN row's files (`app.py`, `styles.tcss`, `screens.py` optional) and the cap of 4; never change an operator verdict (P-D A: status line, bar kept working, no cancel).

**The cap is not the binding constraint.** Every fix recommended here lives in `app.py` (plus at most one rule in `styles.tcss`), so 12a is 1–2 source files. Even the alternatives that add `workspace.py` (B2, B6, B7) or `a2l.py` (Q1 alternative) stay at 3–4. What binds is the node count (about 30 code nodes, Q7) and what can be verified on this host (B2).
