- **Time of check vs time of use (preview → confirm → commit).** `confirm` re-prepares at the Save press and compares the plan and the painted text (`:10968`–`:10981`). A Save before the first refresh passes `painted = None` and can never return go (`:10969`). - **Path length, name length and free space.** G7–G9 run before any read of the target (except SE5-11-2). - **Worker vs main thread.** Preview, confirm and commit all run on the main thread (timer, key handler, dismiss callback). The commit is synchronous, so no write runs at the same time as a preview. The only cross-thread effect is the load worker's main-thread install described in SE5-11-1.
