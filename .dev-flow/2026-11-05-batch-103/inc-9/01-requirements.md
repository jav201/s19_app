## User stories

- **US-103-05** — "The Patch Editor edits a parameter by its A2L definition: scalars, enums, bit masks, text, curves, maps and value blocks." Inc 9 delivers curves, maps and value blocks (I-2 kinds `curve`, `map`, `array`) as pe_C benches inside Inc 8's staging sheet: the rows' summaries, the bench (canvas, legend, tool row, bytes line), the cell cursor and selection, the tools, the op line, and staging a record into the change document over the staged overlay. It carries Inc 2 E3's obligations (plain text, overlay re-encode, long-message cut) and Inc 3a E3's (E3S3-03: decode off the UI thread and page).

## Scope

- **In:** the bench for every row of a bench kind (CTX-PE-BENCH); array rows' cells in the sheet; decoding off the UI thread with a window over large objects; the cursor, the selection and the tools Set, +Δ, ×%, Interpolate, Smooth and Undo; the preview of the record's bytes; staging the whole record; the plain-text and hostile-input rules for every text the bench paints.
- **Out:** editing axis points (the bench edits values only; `E1-rulings.md` D-5); Inc 8's scalar, enum, bit-mask and text editors (unchanged); view levels (backlog item 1); a per-cell unstage (Inc 8 D-4 B); Inc 10's apply cue and export dock (`patch_editor/actions.py`); any I-2 change (`a2l_definition.py` is read only); kinds outside I-2's three (`CUBOID`, `CUBE_4`, `CUBE_5`, `MAP_BLOCK`: kind `""`, no editor, R-PE-DEF.36).
