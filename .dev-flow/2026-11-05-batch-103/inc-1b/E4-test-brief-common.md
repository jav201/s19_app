# E4 independent tester common rules

Work only in your assigned test file(s) and your own `inc-1b/evidence-e4/<role>/` reports/transcripts. Do not edit product, requirements/ledger, other tests or git refs; do not commit/push. You are independent of the DeepSeek implementers. Read `01-requirements.md`, `02-test-cases.md`, `codewire/graph-inc1b.md` and `E2-interfaces.md`; implement discriminating tests from their concrete examples, not from the implementation.

RED must run on the unmodified base `e2e93548` (product/tests match `c062293b`). Use the Linux runner only: `ssh -i ~/.ssh/id_ed25519 -o IdentitiesOnly=yes -o BatchMode=yes <runner>`, Python `~/miniconda3/envs/s19ci/bin/python` with `-I -B`. `/tmp` is full: make a fresh scratch under `~/work`, clone with `git clone --shared /tmp/b103-inc6-merge-final <scratch>/tree`, overlay only your assigned test files, and set TMPDIR/HOME/XDG_CONFIG_HOME/XDG_DATA_HOME/XDG_CACHE_HOME/LOCALAPPDATA to fresh neutral paths there. Close stdin, set `PYTHONDONTWRITEBYTECODE=1`, `PYTHONIOENCODING=utf-8`, disable pytest cache, insert `.` in `sys.path` before import and print `s19_app.__file__` at the top of each transcript. Never touch a real clipboard on the operator PC. Linux uses existing failing OS writer or test-specific recorders; real separate OS reads belong only to the existing isolated Windows CI route. Do not weaken isolation to obtain GREEN/RED.

Tests must not import new product symbols at collection time: base lacks them and RED must be behavioral assertions, not collection errors. Assert exact expected values from the ledger/model, never read expected values from the artifact under verification. Each TC must have a real on-disk node; record full/partial honestly. OS-read/WinCI-only cases may be skipped on Linux with a precise reason but remain not_run, never verified. For right-click use App.post_message of driver MouseDown/MouseUp (and MouseMove for negatives), not Pilot.click. Include mutation targets in your report; no need to run mutants in E4.

Copy the complete RED transcript back into your evidence directory with a per-case result/coverage report and the source/test file hash. Report collected count, pass/fail/skip and why each failure is expected from missing Inc1b behavior. Do not mark tests GREEN here; integration owns GREEN.
