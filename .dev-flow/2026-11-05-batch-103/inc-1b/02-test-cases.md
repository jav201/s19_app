## Common fixtures

- **WinCI** (every case that reads the OS clipboard back). Inc 1a's *isolated clipboard*: the GitHub-hosted `windows-latest` job (`GITHUB_ACTIONS` = `true`, `RUNNER_ENVIRONMENT` = `github-hosted`), asserted before the first write (Inc 1a's R-PASTE.21), skipped by its clipboard probe when the runner's clipboard is unusable (R-PASTE.22). No case runs on a desktop session; none saves or restores a clipboard. If Inc 1a's D-2 is ruled to give Linux an X clipboard, the same cases also run on a private Xvfb display started by the test session, read back by `xclip -o -selection clipboard`.
- **Linux** (the LAN host, no OS clipboard under Inc 1a D-2): the cases that need no read-back (the app clipboard, OSC 52, the notices, a failing write).
- **Separate read.** A system PowerShell `Get-Clipboard -Raw` process (absolute path), as Inc 1a's clipboard probe.
- **Seed.** Before each case the separate process writes `SEED-1b` to the OS clipboard (WinCI), and the test sets the app clipboard to `SEED-1b`.
- **Census session.** `S19TuiApp(base_dir=<tmp>)` at 118×54; `examples/case_00_public/prg.s19` and `synthetic_update_test1.mac` loaded with `load_from_path`, `ASAP2_Demo_V171.a2l` with `load_a2l_from_path` (the app's loaders, copies in `<tmp>`), as `evidence-e1/i1b-e1-census.py` does. Windows reached by their rail keys (`1` Workspace, `2` A2L Explorer, `3` MAC View, `6` Patch Editor).
- **Drag.** `pilot.mouse_down(<view>, offset)`, `pilot.hover(<view>, offset)`, `pilot.mouse_up(<view>, offset)` (C §5's route). **The selection's text** = `app.screen.get_selected_text()` read after the drag (the oracle of what the operator selected).
- **Notices.** The app's notification list after the handlers settle (message, severity), not a spy on a setter.
- **OSC 52 count.** The requests the app sends to its driver, decoded (Inc 1a's R-PASTE.15 method).
- **Failing writer / held clipboard / slow writer.** Linux: every OS layer fails by Inc 1a D-2. WinCI: a helper process holds the clipboard open for 8 s (Inc 1a's R-PASTE.13 fixture).
- **Paste routes.** *P1*: Ctrl+V pressed with the target focused (the app's own paste, Inc 1a's read path). *P2*: a terminal paste: `events.Paste(<separate read>)` posted to the App, as the driver posts it (Inc 1a's R-PASTE.1 method).
- **Targets.** *T1*: the single-line box `#a2l_tags_filter_input` (A2L Explorer, focused with `/`), empty before the paste. *T2*: the multi-line box `#patch_paste_text` (Patch Editor, JSON tab, clicked, its whole text selected with F7 so the paste replaces it, R-TUI-043.5).
- **Right-click (addendum; E3-01).** The driver's route: a `MouseDown` and a `MouseUp`, both `button=3`, at the same `screen_offset`, on the same screen and widget, posted to the App with `app.post_message` back to back (no pause between them, as the terminal's two SGR reports arrive in one read), then the app settles. The press captures the text snapshot; only the valid release copies it, once. **Not** `pilot.click(button=3)`: Pilot posts its events to `Screen._forward_event` and bypasses `App.on_event` (textual `pilot.py:463-468`, B-2 part A), so it skips the app's event entry, and with its pauses between events it also hides the race of B-2 B2. A *right-click on a row* aims at the row's Tag cell (the row index counted below the header) with `out_of_bounds=False` in its cell metadata on press and release.
- **Right-button gesture state (E3-01).** A non-forwarded `MouseDown(3)` captures at most one candidate: non-empty snapshot, `screen_offset`, screen and widget; it starts no copy. Any `MouseMove` whose `screen_offset` differs from the press invalidates the candidate, even if a later move returns to the press cell. A new press, screen change or cancellation replaces/clears it. A non-forwarded `MouseUp(3)` copies only an unconsumed candidate whose offset, screen and widget all match; consume and clear it before the single copy. Every event is forwarded exactly once. *Drag* = press at D, move to M≠D, release at M; *exit-return* = press at D, move to M≠D, move back to D, release at D. Both are cancelled.
- **Table metadata and hostile name (E3A-02, E3A-04, E3-03).** `out_of_bounds=True` is empty space even with a valid row index: no copy, cursor move or `RowSelected`; `False` is a valid row. The exact hostile A2L model name is `HOSTILE_NAME = '[red]\x1b\x07\x1b]52;c;U0VFRF9PU0M=\x07\nSUFFIX'` (Python escapes: `[red]`, ESC, BEL, an OSC-like sequence, LF; no NUL). Expected payloads use this model value, never its painted/replacement-character cell.
- **Quit dialog (addendum).** "Open" = the top screen is the quit dialog and its title, text and button labels equal CTX-COPY's *quit dialog* exactly. The app's run ends when Quit is answered: the test reads the return code and the end time from `run_test`. *Held load*: R-QUIT's fixture (a file load stopped at a held step until the test releases it).
- **Hex view rows (addendum).** "The first painted row" of a hex view = its first painted line read before and after the step (R-COPY.22), never a literal.
