## Change (s19_app/tui/a2l.py only)
1. Tier 0a fast path in _lex_a2l_lines: a string continuation whose element is
   content + exactly one trailing \n (no quote/CR/NUL/embedded end) is appended
   verbatim — one append, no slice, no endswith, no _find_string_end /
   _count_line_ends.
2. Tier 0 fast path for the no-terminator (final) string line.
3. endswith reordered \n-first (single-char checks).
4. _elements: no-progress/no-BOM fast path drops enumerate + 2 if-checks.
