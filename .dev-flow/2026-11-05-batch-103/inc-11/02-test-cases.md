## Common fixtures

- **HDR** — the frame every shape sits in: `ASAP2_VERSION 1 71`, `/begin PROJECT P ""`, `/begin MODULE M ""`, a MOD_COMMON with `BYTE_ORDER MSB_FIRST`, `/begin COMPU_METHOD CM_ID "" IDENTICAL "%.0" ""`, record layouts `RL_U8`, `RL_U16` and `RL_U32` (`FNC_VALUES 1 <type> ROW_DIR DIRECT`), `/begin TYPEDEF_MEASUREMENT T_U16 "" UWORD CM_ID 0 0 0 65535`, and the closing `/end MODULE`, `/end PROJECT`. This is `header()` in `evidence-e1/e1-census.py`.
- **MEAS(X, body…)** — `/begin MEASUREMENT X ""`, ` UWORD CM_ID 0 0 0 65535`, the body lines, `/end MEASUREMENT`. This is `meas()` in the census.
- **SYNMAP** — the synthetic MAP of `evidence-e1/e1-pilot-explorer-widths.py`:
  - `SYN_MAP_W` at 0x1C2D3E00, on `RL_SYN_MAP` (NO_AXIS_PTS_X, NO_AXIS_PTS_Y, FNC_VALUES UWORD);
  - two FIX_AXIS axes of 87 and 13 points, length 2266;
  - an S19 image holding its 2266 bytes.
- **LONGMAP(n)** (E3 correction, R-TUI-042a.3; moved to Inc 12 with its row, 2026-11-07) — SYNMAP with its name replaced by an `n`-character name `SYN_MAP_` + `L` × (`n` − 12) + `_END`; its 34-cell form is `SYN_MAP_LLLLLLLL…` + the last 17 characters.
- **Tracked files** — the 35 tracked `.a2l` files (`git ls-files '*.a2l'`).
- **Reference reading (REF)** — a lexer and field reader written in the tests, importing nothing from the reader. It applies the definitions of `01-requirements.md`. `evidence-e1/e1-census.py` (`ref_lex`, `ref_tree`, `split_header`, `ref_fields`) is its E1 model; E4 writes its own. From the E3 correction (E3A-08): REF's lexer is a character loop like `ref_lex`, not a regex; a static guard (AST and text) shows it imports nothing from `s19_app` and shares no pattern text with `a2l.py`, before any REF case runs; it emits every section's keyword, name, begin words, lines and own runs with their line numbers, and follows D-6 as revised (no "last wins"), the argument rule (a keyword is never an argument) and every row of S2.1/S2.2 added at E3.
- **B3 … B13** — the synthetic shapes of the E3 security probe (`evidence-e3/sec-p_base-transcript.txt`, tags `[B3]` … `[B13]`): [B3] a CHARACTERISTIC with header address `0x2000` and `ECU_ADDRESS 0x3000`; [B3b] the same with `ECU_ADDRESS 0x30_00`; [B4] two ECU_ADDRESS `0x10` and `0x20`; [B5] two LENGTH `4` and `8`, and `DATA_SIZE 2` with `LENGTH 8`; [B6] a VALUE on `RL_U16` with `LENGTH 4`; [B7] two different BIT_MASK; [B8] `BYTE_ORDER` alone on its line, then `BIT_MASK 0x0FF0`; [B9] `ECU_ADDRESS_EXTENSION` alone, then `ECU_ADDRESS 0x1234`; [B10] `MATRIX_DIM x4`; [B13] a file cut inside a MEASUREMENT after `ECU_ADDRESS 0x12`.
- **Hostile corpus** — 160 shapes, every one synthetic:
  - RP-A1 … A29 (29 shapes plus A26b and A26c; line ends, blanks, encodings);
  - RP-B1 … B40 (40 shapes; adjacency);
  - RP-C-* (47 shapes; Inc 2's E3 security shapes);
  - RP-D1 … D4 (INSTANCE and BLOB), from `e1-census.py`;
  - G0 and H1a … H3g (20 shapes), from `e1-probe-glue.py`;
  - K1, K1c, K2, K3, K4, K5, K5b, K7 and K7b (9 shapes; the E2 corpus-class reductions, CG-1), from `codewire/evidence-e2/i11e2-corpus-shapes.py`, each written from a class's structure description only and framed as that script frames it (its HDR has no `T_U16`; K7b declares it);
  - B3, B3b, B5, B6, B7, B8, B9 and B13 (8 shapes; E3S-02, -03, -09: REF shared the argument bug, so the differential gains them) and `/begin /end X` (1 shape; E3S-13: the word after `/begin` or `/end` is consumed whatever it is).
  Each counts once in R-A2L-READ.48/2.
- **Real Explorer** — the app started headless (`tests/support/b100_projects.run_app`) with the size of the case. The flow is: `load_selected_file(image)`, `load_a2l_from_path(a2l)`, then the workers drain. Key `2` shows the A2L Explorer, and the cursor goes on row 0. The painted lines are read back from `render_line(y).text` of `#a2l_tags_list` and `#a2l_detail_card`.
