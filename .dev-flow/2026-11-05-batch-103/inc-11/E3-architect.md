## 2. Answers to the questions routed to E3

### 2.1 Is the reader change the smallest design that fixes every class while keeping the non-defect tags identical?

Yes for the word layer, with three gaps. Alternatives considered:
- (i) A token AST with every reader rewritten over it. It is larger and touches every field rule.
- (ii) E1's CANON pre-pass followed by the base reader unchanged. It needs a second full pass, and the tag reader would still need the header and keyword rules.
- (iii) The graph's design: streaming canonical lines in the base section shape (DE-1, DE-3) plus a word-level tag reader (DE-4). It is (ii) done inline, and it is the smallest.

By class:
- **Corpus classes 2–5 and 7, Latin-1 (CG-5 A), the 47 Inc 2 E3 shapes (RP-C-A … X2, rounds 1–5), the commented copies and the line ends:** mapped to rows and cases (graph table `:100-109`).
- **Class 1 (names):** fixed for tags only (E3A-01, HIGH).
- **Class 6 (lengths):** VAL_BLK is fixed by R-A2L-016 and READ.53; CURVE/MAP go to Inc 3a (CG-4). ARRAY_SIZE is a size class the census oracle does not model (E3A-04).
- **The padding glue:** fixed at the 9-character shape; truncation appears for long names (E3A-03).
- **No regression:** the Issues projection on the 35 tracked files (base reader on E1's CANON, `e3a-issues.txt`) differs from e07fb00 only by V171's `Unclosed /begin sections detected.`, which goes away. Every other A2L code count is equal (no new `A2L_UNRECOGNIZED_BLOCK`, `A2L_DUPLICATE_SYMBOL` or `A2L_BROKEN_REFERENCE`), and REF's diagnostics are `[]` on all 35. That agrees with the 0-error thresholds of READ.4/3, .11/3, .28/3 and .32/4.
