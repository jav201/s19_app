## Remaining product failure (reported, not a test defect)

**`tests/test_b103_a2l_definition_arrays_decode.py::test_r_a2l_def_7_2_arr_1_span_bound_on_computed_length`**

The product returns `Refusal("A2L-DEF-ADDRESS", "VH: the object has no address or no length")` with `byte_length=None`, but the contract (`.7.2/arr-1`; graph-inc3.md line 142 "an array's product as computed") requires `byte_length = element_count × size = 1048577` and the refusal `VH: its span of 1048577 bytes at 0x10 cannot be read`.

Root cause in `s19_app/tui/a2l_definition.py::_describe_array`: the array's `byte_length` is computed only inside the `else` branch after `_place_components(...)`, which returns `None` past `MAX_A2L_DECODE_BYTES`; so the array byte_length collapses to `None` and step (7) fires the wrong "no length" message. An array's byte_length is just `element_count × size` and should not be gated behind component placement (that gate is for curves/maps whose byte_length is the walk's end).

The test assertion was kept unchanged (not weakened).
