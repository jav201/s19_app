## User stories

### US-103-05 — the Patch Editor edits a parameter by its A2L definition (this increment: arrays and axes)
As the operator, I want the Patch Editor to edit a curve, a map or a value block through what its A2L declares — its shape, its axes with their own conversion, the order its values lie in memory — so that the cell I change is the cell the ECU reads, every other cell keeps its bytes, and an axis I edit stays in the order the ECU needs. (PLAN, story 5, pe verdict `mix`; CURVE/MAP/VAL_BLK use pe_C's bench views, Inc 9.) This increment builds only the pure model behind it, extending Inc 2's: what one array, curve or map is (its kind, shape, element count, record and axes), how its record's bytes read as values and axis points, and how an edit becomes the bytes of the record, with the round trip as a requirement. It also gives Inc 6 the full element count of every array kind (PE-D1: the picker cuts arrays to 1 element today). Consumers: Inc 6 (element count, byte length), Inc 9 (the bench views), through interface I-2 (`E1-rulings.md` §4).

## Definitions (CTX-A2L-DEF, Inc 3 additions; terms, formats and lists only)

```text
defined object (adds)  a VAL_BLK CHARACTERISTIC · a MEASUREMENT that has a multi-value MATRIX_DIM
                line · a CURVE CHARACTERISTIC · a MAP CHARACTERISTIC.
MATRIX_DIM value count  The product of the numbers of an object's MATRIX_DIM line; 1 when it has none.
multi-value MATRIX_DIM line  A MATRIX_DIM line other than 1 to 3 words that are each `1`: a line with a
                number above 1, whatever its leading or inner 1s (`1 6 1`, `16 1`), and a line
                R-A2L-DEF.71 refuses (`4 x`, `3 0`, `MATRIX_DIM` alone) (E3A-02).
kind (adds)     array (a VAL_BLK, or a MEASUREMENT that has a multi-value MATRIX_DIM line) ·
                curve (a CURVE) · map (a MAP).
shape           The extent of each index of an array, curve or map, first index first, written
                <n1>, <n1>×<n2> or <n1>×<n2>×<n3>.
element count   The product of the numbers of the shape. A definition has none — no value, never 0 or 1
                (E3A-03) — when the system could not read its shape, read it only in part (a map with fewer
                than two axes read), or refused the MATRIX_DIM line that multiplies it (R-A2L-DEF.145); its
                shape is then () and it has no byte length (E3A-24).
element index   One zero-based index per number of the shape: (i), (i,j) or (i,j,k); for a curve (x),
                for a map (x,y), x the point index on axis X and y on axis Y.
element order   The element indexes with the first index changing fastest: (0,0), (1,0) … (n1−1,0),
                (0,1), (1,1) …
element name    <name>[<i>], <name>[<i>,<j>] or <name>[<i>,<j>,<k>]: the object's name and the element index.
axis            One AXIS_DESCR of a curve or map. Axis X is the first in file order, axis Y the second.
axis name       <name>.X or <name>.Y.
axis point name <axis name>[<k>], k the zero-based point index.
axis header     The words of an AXIS_DESCR from its `/begin` line on (the words after `/begin AXIS_DESCR`
                first, E3A-05), comments left out: <axis kind> <input quantity>
                <conversion method> <max axis points> <lower limit> <upper limit>, then optional keyword
                groups: AXIS_PTS_REF <ref> · FIX_AXIS_PAR <offset> <shift> <count> ·
                FIX_AXIS_PAR_DIST <offset> <distance> <count> · FORMAT "<format>" · MONOTONY <rule word>.
                A FIX_AXIS_PAR_LIST block inside the AXIS_DESCR holds a list of numbers.
axis kind       STD_AXIS (its points are in the object's record) · FIX_AXIS (its points are given by
                FIX_AXIS_PAR, FIX_AXIS_PAR_DIST or FIX_AXIS_PAR_LIST and are not in memory) · COM_AXIS
                (its points are in the record of the axis object it names).
axis object     The AXIS_PTS section an AXIS_PTS_REF names.
AXIS_PTS header The words of an AXIS_PTS section, comments left out: <name> <long identifier> <address>
                <input quantity> <record layout> <max diff> <conversion method> <max axis points>
                <lower limit> <upper limit>, then optional keyword groups.
address word    (the <address> of an AXIS_PTS header) an optional `-`, then `0x` or `0X` and 1 to 8 hex
                digits, or 1 to 10 ASCII digits; any other word is not a number (E3A-14).
point count     STD_AXIS and FIX_AXIS: the max axis points of the axis header. COM_AXIS: the max axis
                points of its axis object's header.
current count   The number of points a record holds for an axis: the number its NO_AXIS_PTS_X or
                NO_AXIS_PTS_Y component holds in the image, or the number of a FIX_NO_AXIS_PTS_X or
                FIX_NO_AXIS_PTS_Y line; the point count when the record layout has neither.
component       A RECORD_LAYOUT line that occupies bytes, words read comments left out:
                FNC_VALUES <position> <datatype> <index mode> <address type> ·
                AXIS_PTS_X|AXIS_PTS_Y <position> <datatype> <point order> <address type> ·
                NO_AXIS_PTS_X|NO_AXIS_PTS_Y <position> <datatype>. A line whose first word is a
                component's and that holds more words than that component lists is not a component
                (E3A-08).
count datatype  The datatype of a NO_AXIS_PTS_X|Y component: UBYTE, SBYTE, UWORD, SWORD, ULONG, SLONG,
                A_UINT64 or A_INT64 (E3S3-01).
layout keyword  A RECORD_LAYOUT line that occupies no bytes: FIX_NO_AXIS_PTS_X|Y <count> ·
                ALIGNMENT_<class> <n> · a line holding only DIRECT.
component count FNC_VALUES: the element count · AXIS_PTS_X|Y: the point count of axis X|Y ·
                NO_AXIS_PTS_X|Y: 1.
index mode      ROW_DIR or COLUMN_DIR: the FNC_VALUES word; the LAYOUT word of a MEASUREMENT.
point order     INDEX_INCR or INDEX_DECR.
address type    DIRECT.
alignment class The ALIGNMENT_<class> line a datatype follows: UBYTE, SBYTE BYTE · UWORD, SWORD WORD ·
                ULONG, SLONG LONG · A_UINT64, A_INT64 INT64 · FLOAT16_IEEE, FLOAT32_IEEE, FLOAT64_IEEE
                their own name.
record          The bytes of an object from its address: its components, each at its offset.
shared section  A RECORD_LAYOUT, AXIS_PTS, COMPU_METHOD, COMPU_TAB, COMPU_VTAB or COMPU_VTAB_RANGE section that
                more than one object names, or a MOD_COMMON that more than one object lies under (R-A2L-DEF.148).
                An object names a section directly or through another section: a COMPU_TAB, COMPU_VTAB or
                COMPU_VTAB_RANGE named through a COMPU_METHOD is named by every object that names that method
                (E3S3-33).
byte length     (of an array, curve or map) the byte length of R-A2L-DEF.74 or .75 — the length
                R-A2L-DEF.7 and .26 read for these kinds.
element definition  The definition of one element or one axis point: the kind number or enum of its
                conversion method; the conversion method, display format, unit, limits, extended limits,
                bit mask and enum table of the object (of the axis header, for an axis point); the
                datatype of its component; its element name (axis point name) as name; the address of
                its bytes (none for a FIX_AXIS point).
stored point    The stored value of an axis point.
fixed point     A stored point of a FIX_AXIS. Each number of its FIX_AXIS_PAR, FIX_AXIS_PAR_DIST or
                FIX_AXIS_PAR_LIST is first read as an IEEE double (a word with more digits than a double holds
                is rounded there: `9007199254740993` reads as 2^53); from those doubles, a point that is a whole
                number is exact, and any other point is the double nearest it (E3S3-15).
monotony rule   The order the stored points of an axis follow in point index order, each compared with
                the one before: STRICT_INCREASE greater · STRICT_DECREASE smaller · MON_INCREASE not
                smaller · MON_DECREASE not greater · STRICT_MON all greater or all smaller ·
                MONOTONOUS all not smaller or all not greater · NOT_MON any. The rule word is the
                MONOTONY word of the axis header; with no MONOTONY word, STRICT_MON.
breaking point  The first point, in point index order from point 1, whose stored value does not follow
                the monotony rule with the points before it.
edit            A set of pairs (position, operator text) for one array, curve or map. A position is an
                element index, or an axis letter (X or Y) and a point index.
edit order      The points of axis X by point index, then those of axis Y, then the elements in element
                order.
whole number    (the MATRIX_DIM, NUMBER, LENGTH and DATA_SIZE numbers, component positions, the
                FIX_NO_AXIS_PTS_X|Y and ALIGNMENT_<class> numbers, max axis points, the count of a
                FIX_AXIS_PAR or FIX_AXIS_PAR_DIST line) a word of 1 to 9 ASCII digits (U+0030 … U+0039),
                read in decimal; a longer word, a sign, a point or any other character is not a whole
                number (Inc 2's count rule, E3S-03; every such word of the 35 tracked `.a2l` files has
                1 to 9 digits, this pass's grep and census).
array refusal order   name (R-A2L-DEF.6, .139), kind (.4), MATRIX_DIM (.71; then .145 for a curve or map),
                a MEASUREMENT's datatype (.8, E2-1), record layout (.82), positions (.87),
                parts (.84), modes (.85), component datatypes (.86, the count datatype included), FNC_VALUES
                (.83), axis count (.91), then for axis X and then for axis Y (each axis all its checks
                before the next, E2-4, E3A-11): axis kind (.92), axis object (.96), axis object layout
                (.97), point count (.95, .142), fixed points (.98, .141, .147), fixed point count (.99), axis
                component (.101), FIX_NO current count (.116.1, .117.1), axis object record (.143); then
                three-dimension COLUMN_DIR (.80), alignment (.144, .89), shape from the length
                (.70), length (.76), address and length (.7.1, .7.2), the values' refusals (.81, in Inc 2's
                refusal order), the axis points' refusals (.103, axis X before axis Y). For a VALUE, .145
                applies right after the kind (.4) in Inc 2's refusal order.
array encode order    the definition's refusal, then A2L-DEF-PARSE (.152 of Inc 2), then the record's
                decode (.124) or single-value ELEMENTS (.120), positions (.125), then each edit in
                edit order: fixed axis (.126), common axis (.127), no points (.128), unknown monotony
                (.154), then Inc 2's encode order for its element definition; then the monotony of
                axis X, then of axis Y (.129), with OVERLAP late (.138 of Inc 2, .140).
placeholders (adds)   <axis name> <axis point name> <element name> as defined above · <layout> the
                record layout name as the file writes it · <component> the line's first word; for a
                component line with more words than its component lists, the first extra word (E3A-08) ·
                <class> the alignment class of an ALIGNMENT_<class> line (BYTE, WORD, LONG, INT64,
                FLOAT16_IEEE, FLOAT32_IEEE, FLOAT64_IEEE) ·
                <word> a word as the file writes it, or (none) when there is none (in every refusal
                message, each file word it echoes — <name> and <layout> included, and the name in an
                axis, element or axis point name — is written as R-A2L-DEF.151 writes a file word,
                E3S3-22, -25) · <ref> the
                AXIS_PTS_REF word, or (none) · <dims> the words of the MATRIX_DIM line, or (none) · <a> <b> byte
                offsets in decimal · <c> a current count · <m> <n> <k> counts in decimal · <bytes> a byte
                count · <count> an element count · <letter> X or Y · <rule> the monotony rule word ·
                <position> for a valid position, its element or axis point name; for a malformed position, the bounded `repr(position)` · <point text>
                the display text of the breaking point's decoded stored value.
```

Terms reused without change: Inc 2's CTX-A2L-DEF (definition, refusal, notice, display text, operator text, stored value, the refusal and encode orders, the placeholders); CTX-A2L-TAG (address, length, datatype, record layout, byte order, conversion method, axis); CTX-A2L-VALUE (tag span, raw value, conversion error); CTX-A2L-FILE (CHARACTERISTIC kinds, multi-value tag).
