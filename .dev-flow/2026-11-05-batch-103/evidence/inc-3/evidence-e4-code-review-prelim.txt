## Confirmed findings

**F1 — impl, HIGH — `s19_app/tui/a2l_definition.py:831`**
A definition refused with `A2L-DEF-KIND` (kind `""`: CUBOID, CUBE_4, vendor kinds) gets `element_count=1`, not `None`.
```python
return Definition(
    ...
    kind=kind or "",                                   # :810
    byte_length=None if value_145 else tag_length,     # :812
    ...
    element_count=None if value_145 else 1,            # :831
)
```
`value_145` is only set for a VALUE with a multi-value MATRIX_DIM, so the KIND-refusal path (`kind is None`) falls through to `1`. This violates the pinned E3A-03 ruling and the graph `_describe_one` node — *"Every definition of kind `""` (`A2L-DEF-NAME`, `A2L-DEF-KIND`) gets `element_count` `None`"* — and the case expectations `R-A2L-DEF.4/9` (`ASAM.C.CUBE_4.ROW_DIR → kind "", element count None (not the default 1)`) and the D-14 `R-A2L-DEF.24/1` changed case. The `.4/9` negative control is literally "element count 1 → RED", so this case will go RED. The `A2L-DEF-NAME` path is correct (it uses `_empty_definition`, element_count `None`); only the KIND-refusal path is wrong. Fix: `element_count=None if (value_145 or kind is None) else 1`.

**F2 — design-gap, LOW — `s19_app/tui/a2l_definition.py:1528,1557,1581`**
`_read_fixed_rule` selects the FIX form by fixed priority `FIX_AXIS_PAR` → `FIX_AXIS_PAR_DIST` → `FIX_AXIS_PAR_LIST`, whereas the graph `_read_axis` node pins *"the first of `FIX_AXIS_PAR o s n`, `FIX_AXIS_PAR_DIST o d n` (header words) and the numbers of the `FIX_AXIS_PAR_LIST` child **in file order**"*. A FIX_AXIS carrying both PAR and PAR_DIST would prefer PAR regardless of which appears first. No fixture or case exercises two FIX forms on one axis, so nothing goes RED — but it is a silent contract deviation.
