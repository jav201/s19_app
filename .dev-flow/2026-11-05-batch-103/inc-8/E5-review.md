## Security lens (one pass)

- **Paths.** Inc 8 opens, writes and names no file. A stage writes only the in-memory change document. Save is unchanged.
- **Untrusted A2L text.** Every sheet cell, detail line and bar text goes through `plain` / `clip(clean=True)` into rich `Text`, where markup is never parsed. Status lines go through `name_echo`. R-PE-DEF.70 … .73 tests are GREEN (`evidence/e5/g1.txt`, `g2.txt`, `g4.txt`). Gap: F-9.

- **Clipboard.** Inc 8 adds no clipboard reader or writer. `OsClipboardInput` predates it. The tests stand in for the clipboard and never read it.
