- Let events settle and the relevant worker finish before read-back. Read actual visible widgets, tables, labels and modal stack, not only internal state. Check and Patch cases keep the named editor visible throughout the transition and never re-enter it. No case uses manual refresh.
- **F** is an ordered test spy on the proposed common fan-out and its existing UI seams.
