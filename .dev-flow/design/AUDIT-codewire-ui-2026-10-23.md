## 1. Verdict

**The UI lies, or does nothing, on four common paths, and only one of these four was known.**
1. **Load project cannot load a project from its own dialog.** The Load button sends the name `Label()` (CW-U-1).
2. **After every file load, the focus moves to the hidden Split/Join/Export table.** That table eats `p`, `t`, `k`, `g`, `d`, `j` and others, so the key bar and help promise keys that do nothing (CW-U-2).
3. **The Bytes field reads `11 22` as decimal.** The paste JSON and the change files read the same text as hex. A pasted hex dump becomes other bytes with no warning (CW-U-4).
4. **The UI shows state from the wrong source.** The Workarea Files list is always empty (CW-U-3). The CRC Designer preview keeps the previous image's CRC (CW-U-8). The Patch Editor card treats the patched image as "was" (CW-U-6). The Check Editor validates the image against itself (CW-U-9).

**Counts:** 18 findings. 13 are NEW: 3 HIGH, 8 MEDIUM, 2 LOW. 5 are known: the UI half of RW H-2/H-4/H-10, PH-2, PL-2 and the Load-dialog backlog entry (PM-1), each re-observed with screen text.
