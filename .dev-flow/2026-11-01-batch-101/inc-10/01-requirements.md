## User stories

### US-HEXNAV-1 — a jump shows me its target
As the operator, I want every go-to, search hit and section, tag, record, issue or map jump to show the target row near the top of the hex pane, scrolled to the left edge, and the `> ` marker only on a go-to I just made, so that I never scroll to find the row I asked for. (F-07, D4-2, D4-6.)

### US-UNLOAD-1 — the status line describes what is loaded
As the operator, I want the file status to say what I just unloaded, to say `Nothing to unload.` when nothing was loaded, to drop the diagnostics of an unloaded image, and to show file names without format characters, so that the status line never describes a file that is gone or a name that is not its own; and I want a project I save and a question I am asked after an unload to name no file I unloaded. (F-13, D5-17, D5-19, D5-27, SE5-12a-2; E3 S-2, S-5.)

### US-FOCUS-2 — the keys reach the window I see
As the operator, I want the focus on the shown window after a rail key, after closing Split / Join and after an unload, so that my next key never lands in a hidden widget, and a key never runs a control of a hidden window. (F-14, D17-38, D6-21; E3 A10-01, S-3, S-4.)

## Definitions

- **In-place write** (Inc 5 definition, S9 / S13; **scope widened** to S2 CTX-A2L and S17): a Patch Editor apply (whatever its status), a Patch Editor save-back (whatever its outcome), or a Save project commit that writes the image. The `current_file` object is kept; its bytes change.
- **Jump** (S4 CTX-HEX, new term): a hex view showing a new target: a go-to hit, a search hit, or a selection of a section, an A2L tag (select or tag find), a MAC record, an issue or a Memory Map cell.
- **Second row** (S4 CTX-HEX, new term): the second hex row of the view, below its notice lines. **First view row**: the first of the view rows.
- **View rows** (S4 CTX-HEX, new term, E3 A10-03): the rows a hex view can show, in address order — the present rows and the rows R-TUI-004.3 adds for MAC records outside the image. Windows, pages and the row above a target are counted in view rows; the target row itself is still CTX-HEX's (a present row, R-TUI-018.3).
- **Next hex page** (S4 CTX-HEX, amended): the hex page that starts at the first view row after the shown window. **Last page shown**: the shown window holds the last view row. After a jump the window starts one view row above the target row and may hold fewer rows than the hex page size.
- **File status** (S6 CTX-SHELL, amended): the last file status the system set: a load's load status (S5 CTX-FILES), **an unload's unload status (R-WS-LOADED.13)**, a project load's project line (S11). `Ready.` until the first.
- **Fixture three** (test term): an S19 image of three 8-byte ranges `0x8000` (bytes `00`…`07`), `0x8010` (eight `FF`), `0x8020` (`20`…`27`). **Case 08**: `tools/synth/make_release_case.py` seed 20260001, 1.0 MB (`firmware.s19`, `firmware.a2l`, `firmware.mac`; 26 546 present rows). **Join-fill pick**: Split / Join in join mode, gap fill, pad `0xFF`, ranges `range_00` and `range_02` picked.
