Common fixtures:
- **Census (AST)** — the static census of `s19_app/` (I-5 of `codewire/graph-inc12.md`; it imports no `s19_app` to walk the source; the test may import the package for the toolkit bindings). *Dialogs* = every `ModalScreen` subclass; an *opener* = a construction of the class outside its own body inside a reached function, a subclass's opener counting for its base (E3A-02). *Actions* = every `action_<name>` method of every class. An *action string* is a string literal, not a docstring, that is wholly `<name>`, `<name>(<args>)`, `app.<name>` or `screen.<name>` (a binding's or a palette entry's action, or a `run_action` argument), or the target of an `@click=` link. A *reach* = an action string naming `<name>`; a `BINDINGS` action declared on a toolkit base class of the method's class (read from the installed `textual` classes' `BINDINGS`: `Input`, `TextArea` → `cut`, `copy`, `paste`); or a call or reference `.action_<name>` inside a reached function. A *reached function* = an action that has a reach, a method the toolkit runs by its name (`on_*`, `_on_*`, `compose`, `watch_*`, `validate_*`, dunders), or a function that a reached function calls or passes (a fixpoint, searched backward from each call-only action; references count, so `call_later(self.action_x)` is a reach). Words in messages, docstrings and comments never count (E3A-01). Limit, stated: a product binding's action string counts for every action of that name, whatever its class (E3A-01 (c); no instance on the base).
- **State walk** — mount the app at 118×54, show the window through `action_show_screen`, and after each state collect the ids of the window's widgets that are shown (`tests/b97_probes.is_displayed`). The *population* is the union of the ids of the widgets mounted in the window in any walked state; an id is *never shown* when it is in the population and in no collected shown set. Each walk asserts its population size first (a vacuous walk fails; E3A-03).
- **Reports project** — `tests/b97_fixtures.make_project(app, "proj1")` and `load_project` (the app's own load), then `reports/20261106T100000Z-report.md` (`# Report one\n\nbody\n`), `reports/20261106T110000Z-report.md` (`# Report two\n`) and `filters/f1.json` (`{}`); the dialog opened with `t` (the pilot's shape, `evidence-e1/i12e1-pilot.py`). **Known focus** (U-2) — before `t` the test records `app.focused` (asserted not `None`) and the shown window. **Empty Reports project** — `proj2`, no `reports/` folder. "Closed" = no `ReportViewerScreen` on the screen stack and the app's main screen on top. **Folder spy** — `open_folder_in_file_manager` replaced as in `tests/test_open_folder_chips.py:113`, counting calls.
