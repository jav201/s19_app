Common fixtures:

- **State walk** — mount the app at 118×54, show the window through `action_show_screen`, and after each state collect the ids of the window's widgets that are shown (`tests/b97_probes.is_displayed`); a widget is *never shown* when it is mounted in the window and in no collected set. Each walk asserts its population size first (a vacuous walk fails).
- **Reports project** — `tests/b97_fixtures.make_project(app, "proj1")` and `load_project` (the app's own load), then `reports/20261106T100000Z-report.md` (`# Report one\n\nbody\n`), `reports/20261106T110000Z-report.md` (`# Report two\n`) and `filters/f1.json` (`{}`); the dialog opened with `t` (the pilot's shape, `evidence-e1/i12e1-pilot.py`). **Empty Reports project** — `proj2`, no `reports/` folder. "Closed" = no `ReportViewerScreen` on the screen stack and the app's main screen on top. **Folder spy** — `open_folder_in_file_manager` replaced as in `tests/test_open_folder_chips.py:113`, counting calls.
- **FX project** — `tests/b97_fixtures.fx_project` (opened through the app's own load); `flash_chain` imported with `tests/b97_fixtures.import_lanes` and run with `run_lanes`; it waits at block 3 (the external step).
