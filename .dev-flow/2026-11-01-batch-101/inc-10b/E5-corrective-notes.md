## 4. Decisions taken in this pass

- **E-1 (R-1: where the changed bytes come from).** The written spans are not passed to the hook (its three callers and the change service are outside the slice), so the bytes the write changed are found per tag: a tag is recomputed when the bytes its row was computed from differ from the image's bytes at its range now. That covers the apply, the save-back and the commit alike, and it cannot miss a byte a writer changed outside its document's spans (a re-derive). Cost on case_06: 0.370 s, most of it the loop over 220,040 rows and the position map; a span index was not needed for the bound.
- **E-2 (R-2: the notice's place).** The ruling says "run the Split/Join notice first, so a failure later in the hook cannot skip the disarm"; the notice is now the hook's first statement, before Inc 6's body, not only before the hex refresh (the review's minimal form). The window's `_bump` / `_sync` read only `current_file.mem_map` and the window's own state, so no earlier step feeds it.
- **E-3 (R-2: no node).** The miss needs an Apply processed between a reload's end of busy and its `_step_a2l`, after an A2L re-parse that returned no data (the review's window, not reproduced). No shipped control reaches that window deterministically, so the fallback is recorded as defensive, as the ruling allows.
- **E-4 (R-6: the guards).** Each new notice queries the panes it paints in one `try` at its top and returns when one is missing, as the old notices skip their own panel. In the A2L notice the guard comes before the recompute, so a headless path without the A2L Explorer computes nothing (as the old notices do nothing for a missing panel).
- **E-5 (QA-2: the case's precondition).** Textual 8.2.8 keeps a column's `content_width` across `DataTable.clear(columns=False)` (`_update_column_widths` only widens on add), so after case 08's first page the Raw and Physical columns are 18 cells wide (measured: e5c-04, `the Raw column is already 18 cells wide`). The audit's "a filter or page on which every shown Raw cell is narrower" therefore cannot make a 5-character value wider than the column. The case writes a 22-character FLOAT32 value instead (`EA A3 64 C6` at `VALUE_0007`), and reads the painted cell from the rendered line at the column's painted offset, with the table scrolled so Raw is its first shown column (the table is 50 cells wide: a probe of the geometry, not committed).
- **E-6 (QA-4: the wait).** The node now waits until the pane changed after the write (the written byte painted at `0x960`, or the window moved) and asserts the window, the byte and the scroll after it. This was done on the assumption that under M-B2 the row `0x960` would no longer be painted and the old wait would time out before the window clause. That assumption is wrong for this geometry: a hex page is 200 rows (`hex_rows_page_size`, A:2822), so from row 0 the row `0x960` (view row 150) is still painted, and DeepSeek's M8 on the pre-corrective node is RED at the window clause too (`E5-mutants.md`). The new wait is kept: it changes no verdict here (base RED at the wait; M-B RED at the scroll; M-B2 RED at the window, mut-c-08, mut-c-09) and it still holds where a moved window no longer paints the written row.
- **E-7 (QA-7: applied, not only recorded).** The fix QA-7 names is one wait per press; it was applied in the three helpers (no node body changed).
- **E-8 (ids).** QA-2's case takes R-A2L-048/4, as ruled; R-4's node takes the next free id, R-A2L-048/5 (the requirement it guards is R-A2L-048's values; the summary, names and cursor are asserted with it). Mutant ids M-c02 … M-c12 match their transcripts; M-W = M-c07, M-B2 = M-c08 and M-c09.
- **E-9 (the law guard caught the QC-TM node).** The first final pass (tree `f60e3b2d…`) failed `test_suite_hygiene.py::test_r_tst_040_041_every_upper_timing_bound_is_reported`: the re-pointed node compared `elapsed < bound` with `bound` taken from `report_margin` two statements earlier, and the guard accepts only the inline `assert elapsed < report_margin(...)` form (e5c-14). The node now asserts the bound inline, first, and the equality to a full recompute after it (W:1590-1603). That is the only change between the two trees; the QC-TM mutants and every final run were re-run on the new tree.
