Common fixtures:
- **State walk** — mount the app at 118×54, show the window through `action_show_screen`, and after each state collect the window's widgets that carry an id, over the whole window (`#screen_flow` / `#screen_flow_execution`: its header, the window itself and its panel), and which of them are shown. A widget is *shown* when `display` holds on it and on every widget that holds it, up to the screen (`tests/b97_probes.is_displayed`, CTX-SHELL's "displayed"); `visibility` and the region's size are not read. The *population* is the union of the widgets with an id mounted in the window in any walked state, counted by widget identity (two widgets that share an id, such as Textual's internal `label` of each Select, are two members); a member is *never shown* when no collected state shows it. Each walk asserts its population size first (a vacuous walk fails; E3A-03; whole window and identity: E5 QA-1, QA-7). Every state is driven through the product's controls (chip presses, Add, Run, Save Set), never by setting widget state directly.
- **FX project** — `tests/b97_fixtures.fx_project` (opened through the app's own load); `flash_chain` imported with `tests/b97_fixtures.import_lanes` and run with `run_lanes`; it waits at block 3 (the external step).
- **Flow Builder** — FX project; the Flow Builder shown (`tests/b97_fixtures.open_flow_builder`).
