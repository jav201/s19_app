Common fixtures:
- **State walk** — mount the app at 118×54, show the window through `action_show_screen`, and after each state collect the ids of the window's widgets that are shown (`tests/b97_probes.is_displayed`). The *population* is the union of the ids of the widgets mounted in the window in any walked state; an id is *never shown* when it is in the population and in no collected shown set. Each walk asserts its population size first (a vacuous walk fails; E3A-03). Every state is driven through the product's controls (chip presses, Add, Run, Save Set), never by setting widget state directly.
- **FX project** — `tests/b97_fixtures.fx_project` (opened through the app's own load); `flash_chain` imported with `tests/b97_fixtures.import_lanes` and run with `run_lanes`; it waits at block 3 (the external step).
- **Flow Builder** — FX project; the Flow Builder shown (`tests/b97_fixtures.open_flow_builder`).
