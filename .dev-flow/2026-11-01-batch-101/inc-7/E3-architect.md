## Points checked with no finding

- **`_window_rows` format.** Identical to `render_hex_view` rows under the cap (probe above, `executed`). No header line remains, because the only header lines `render_hex_view` can emit here are the two cap lines. `high > low` is guarded by every caller, so the `No data available.` branch was never reachable. `HEX_WIDTH` stays imported, so the census `tests/test_render_hexview.py` `MEASURED_CONSUMERS` (which lists `diff_report_service`) holds. No product module outside `diff_report_service.py` calls `_window_rows`.
- **Threshold arithmetic (`executed` by hand).** 10,240-byte run: window 0x0FC0 … 0x3800 = 644 rows. 69,632-byte only-B run: 0xFFC0 … 0x21000 = 4,356 rows; M2 stops at 4,100 rows (4 unmapped rows, then 4,096 × 16 = 65,536 bytes). 8,960-byte before/after run: 564 rows. All three match the records.
- **Double escaping.** Only the A2B external arm pre-escapes before the generators (`flow_execution_service.py:984`, `:986`; grep of `md_safe(`/`md_code(` outside the report modules). The chain-set report escapes at its own sink and is untouched. The HTML helpers read raw values plus `_esc`. They do not read the Markdown lines back, except the Checks addendum through `_md_unescape` (OBS-7-2, out of scope). AT-B94-18 / TC-B94-25 check that `\[red\]` is present, and that substring is absent from the double-escaped `\\\[red\\\]`, so M12 is killed. `_md_text` escapes the backslash before the pipe, which also closes the B-10 shape (`\|` in the raw value) for the linkage Symbol cell.
- **App wiring (I-4).** All three reads happen before `_busy_begin_action` (F-10 holds). Each read is a reference, and no code mutates `mac_records`, `_a2l_enriched_tags` or `current_a2l_data` in place (grep), so the worker gets a stable snapshot. `_compute_a2l_enriched_tags` is cached by `(id(a2l), len(mem_map))`. The filter branch and the A↔B report already call it on the UI thread; a cache miss after a create-into-hole apply costs one `enrich_tags_and_render`, the same cost those paths already pay. New worker parameters are keyword-only after `gen`, so `test_tc_b100_51_workers_take_the_run_generation` and the A12-28 seam census hold.
- **D-3.** Every MAC load sets `mac_path` (`app.py:16535`, merge `:16744`), and `load_service.py:79-80` gives `mac_path=None, mac_records=[]` for an image without a MAC, so `mac_path is None` is the correct "no MAC" test.
- **D-1.** `provenance=` has one product caller (`before_after_service.py:353`), and no product code reads a report's title. M4 and M5 guard the rule.
- **Interfaces with other increments.** Inc 8 and Inc 9 change other arms of `run_flow`. Inc 3 changes other `app.py` functions. Inc 6 rebases on `action_before_after_report`. The rebase after Inc 2's golden change is recorded. No clash found.
