# Inc 7 — test cases (ISO/IEC/IEEE 29119-3), E1

One case per coverage item `<requirement id>/<n>` of `01-requirements.md`. Written at E1, before any test: **Coverage** is `gap` where the test does not exist yet (E4 writes it), and **Result** is `not_run` everywhere. Test names are E1 proposals (prefix binding: `test_r_<area>_<id>_…`; the rest fixed at E4); new tests go into `tests/test_diff_report_service.py` (generator cases) and `tests/test_before_after_report.py` (composer and key-`b` cases) (D-8). Class: *normal*, or *robustness* for an `If` row. "Composer" = `compose_before_after_report` with a project folder, the original image and the saved patched image on disk (the existing `_summary` / `_make_s19_image` fixtures: both images map `0x100 … 0x103`, the patch changes `0x100 … 0x101`, one run `0x00000100 … 0x00000102`). Expected results are the requirement's exact text.
