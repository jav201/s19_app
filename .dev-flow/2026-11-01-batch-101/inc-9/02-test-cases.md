# Inc 9 — test cases (ISO/IEC/IEEE 29119-3), E1

One case per coverage item `<requirement id>/<n>` of `01-requirements.md`, plus the acceptance cases `AT-I9-1` … `AT-I9-3`. Written at E1, before any test: **Coverage** is `gap` (E4 writes the test) and **Result** is `not_run` everywhere. Test names are E1 proposals (`test_r_<row id>_<n>_…`, fixed at E4) in the two new files of `E1-slice.md` §6: G-T1 = `tests/test_b101_flow_saves.py` (service), G-T2 = `tests/test_b101_flow_names_ui.py` (app, keys and dialogs). Class: *normal*, or *robustness* for an `If` row. Expected results are the requirement's exact values; "base" gives what `98d94d7` does (B = the E1 pilot, R = read).

Common fixtures:
- **FX project** — `tests/b97_fixtures.fx_project` (opened through the app's own load): flows `patch_chain`, `flash_chain`, `patch_chain_b`, … ; `flash_chain` = LOAD → PATCH → EXT-STEP (log `flash_log.txt`, output `fw_app_flashed.s19` in the project) → WRITE-OUT. **Set P** = Import… of `patch_chain`, `flash_chain`, `patch_chain_b` (in that order), mode `parallel`, Run; `flash_chain` (lane 1) waits at block 3. **Set S** = the same lanes, mode `sequential`, Run. **Evidence** = `tests/b97_fixtures.flash_evidence` after the Run. "New report" = a `reports/*-chain-set-report.md` not there before the action.
- **Builder project** — `tests/b97_fixtures.flow_project` (flows `patch_chain`, `flash_chain`, `crc_chain`; `prg.s19`), Flow Builder shown, `patch_chain` loaded through Load… (`tests/b97_fixtures.load_flow`).
- **Project W** — `<tmp>/.s19tool/workarea/p` holding `prg.s19`; work area root `R` = `<tmp>/.s19tool/workarea`. **Folder O** = `<tmp>/outside/` (not under `<tmp>/.s19tool`). **Link(a → b)** = `tests/b97_fixtures.make_junction` for a folder (a junction on Windows, a symlink elsewhere); `os.symlink` for a file.
- **Evidence state per arm (E3A-08).** Every link case has a Linux arm (symlink), run at E5 on the Linux hosts, and a Windows arm (junction), run at E5 on the Windows PC under the Windows-only-arm rule (isolated app-state folders, never the clipboard), as Inc 15's was; each arm is `not_run` until it runs. A file link (`os.symlink`) needs the symlink privilege on Windows: the Windows arm of R-FLOW-FILE.14/1 and R-FLOW-SET.8/1 is a dangling junction named like the file, and E5 counts it RED on base only after measuring that the base save follows it.
- **Flow F1** = `Flow(name="a", blocks=[SourceBlock("prg.s19")])`. **Set C1** = `ChainSet(name="s", chains=(ChainSetEntry(chain="x", template="x", inputs=((0, "prg.s19"),), outputs=()),))`. **Flow rep_a** = `tests/b97_fixtures.write_flow(<project>, "rep_a", [SourceBlock("prg.s19"), ReportBlock()])` (REPORT-bearing; the palette offers no REPORT block, so the fixture writes it).
- **Create spy** = `os.open` wrapped (monkeypatch) to record every path it is called with, then call through (the claim primitive, graph I-7). **Windows follow (emulated)** = `os.open` wrapped so that its call for the first free candidate creates `<O>/followed.json`, puts a file symlink to it at the candidate and returns the descriptor of `<O>/followed.json`: what Windows `O_CREAT|O_EXCL` does through a dangling link (house finding S-F1, `workspace.py:1250-1256`), runnable on Linux.
