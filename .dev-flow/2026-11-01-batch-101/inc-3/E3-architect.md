## Answers to the points the orchestrator flagged

- **Dropping `resolve()`: which files are gathered, and the guards.** The set changes only where a True "already home" skip becomes a library lookup: a link loop on the name (F1), and on POSIX a `..` over a missing folder (F5). No containment or junction check lives in this limb. Copies keep `_check_home_contained`, `place_into_workarea(workarea_root)` and the writer's entry walk, so a composition name cannot move a read or write outside the project. Windows long paths and `..` behave the same in both forms (the Win32 layer folds them before the call).
- **R-PROJ-GATHER.13: what the save writes for that name.** Nothing that lasts. The gather copies the library `x.json` to `patches/x.json`, the writer then refuses the batch entry `x.json` as a link, `project.json` is not written, and the rollback removes the copy. The status is R-PROJ-ROLLBACK.9's line (F1).
- **R-TST-110..113 stop stamp.** The signal is public. It fires once per layout pass, and the helper keeps the first with a height. It can fire before the summary exists, and the height check guards that. Callback errors are swallowed. The ordering against the compositor holds only outside `batch_update`, which the app does not use today (F3). The verifier needs a design (F2).
- **Overlap with Inc 2's wraps.** The line numbers in `E1-slice.md` match `b101-inc2` (`:774`, `:796`, `:887`, `:921`, `:1325`). The edits keep each bound's `report_margin` call, so the R-TST-049 guard stays quiet only when two conditions hold. PR #212 must be in main before E4 (still OPEN now). No edited function may gain a `report_margin` call (F9).
