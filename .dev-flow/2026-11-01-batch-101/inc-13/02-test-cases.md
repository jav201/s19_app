# Inc 13 — test cases (ISO/IEC/IEEE 29119-3), E1

One case per coverage item `<requirement id>/<n>` of `01-requirements.md`. Written at E1, corrected by the E3 round-1 rulings (`E3-rulings.md`), before any test: **Coverage** is `gap` where the test does not exist yet (E4 writes it) and `covered` where an existing test asserts the expected result; **Result** is `not_run` everywhere. E4 integration (`E4-integration-notes.md`) filled **Coverage** and **Result** from the LAN Linux host 2 runs in `../evidence/inc-13/int-*.txt`. The E5 corrective pass (`E5-corrective-notes.md`, rulings `E5-rulings.md` C-1 … C-8) applied the coverage audit (`E5-coverage-audit.md`), added the cases marked *(E5c)*, and re-filled **Result** from its LAN Linux host runs (`../evidence/inc-13/e5c-*.txt`: `e5c-lane1` for the parallel lane, `e5c-serial-r1` … `-r5` for the timing arms). Test names are the E1 proposals of `E1-slice.md` §2. Class: *normal*, or *robustness* for an `If` row. Platform: the LAN Linux host (the E1 host runs nothing); Windows where the orchestrator adds it.

Shared terms (see `01-requirements.md` Definitions): **fixture image** = `_fixture_mem()` of `tests/test_crc_designer_view.py` (`0x8000`–`0x8007` = `00`…`07`, `0x8010`–`0x8017` = `10`…`17`, `0x8008`–`0x800F` absent), whose CRC-32/ISO-HDLC oracles under the first-shown Ranges `0x00008000-0x00008008, 0x00008010-0x00008018` are concat `0x9C5BCBBD` = `zlib.crc32(bytes(range(8)) + bytes(range(0x10, 0x18)))` and fill(0xFF) `0x2A8A3950`. **Dirty fixture** = the fixture image plus `0x800B` = `0x99` (a present byte in the join gap). **Recompute count** = `designer_recomputes()` of `tests/support/b101_designer.py`: calls of `CrcDesignerPanel._recompute`, counted by a class-level wrapper the fixture `designer_recompute_counter` installs before the app starts; `before` = the count taken just before the input. **Injected quiet time** = `crc_designer_view.CRC_RECOMPUTE_S` replaced by monkeypatch (read when a recompute is scheduled). **Injected cap** = `crc_designer_view._COVERAGE_CAP_BYTES` replaced by monkeypatch (read at each recompute). **Wait for the recompute** = `wait_designer_recompute(pilot, app, before)`: `wait_until(…, pause_first=True)` (Inc 2's yielding wait) until the recompute count is above `before` and `_pending_recompute is None`; the same definition in every case and in the waits of `E1-slice.md` §3 (E3 ruling A-3). No case decides by sampling the clock outside the serial-lane timing arms (E3 ruling A-2).
