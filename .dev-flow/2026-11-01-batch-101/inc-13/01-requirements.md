## User stories

### US-CRC-RESP-1 — the CRC Designer stays usable with the 10 MB demo image
As the operator, I want a CRC Designer edit, a preset pick and a template load to update the results within a few seconds when the coverage spans the 1.2 MiB calibration region of the 10 MB demo image, so that the screen does not freeze for about 10 s per keystroke and about 2 min per template load (F-23, guide ch12.4).

### US-CRC-FRESH-1 — the CRC Designer's coverage follows the loaded image
As the operator, I want the coverage preview and the coverage window to show results for the image I have just loaded (and the empty-state note after I unload it), so that the CRC Designer never says "Load an image to preview coverage CRCs over real bytes." while an image is loaded (F-24, guide ch12-01).

### US-SEG-RESP-1 — the Split/Join preview stays usable with the 10 MB demo image
As the operator, I want the Split/Join preview to update within a few seconds when I switch a join to fill over the demo image, with the same band, counts and state line as today, so that I can see the conflict before I export (F-23, guide ch14.6, about 25 s today).

## Definitions

- **Result surface.** One of the six result surfaces of S13 CTX-DESIGNER: the self-test verdict, the custom-vector CRC, the JSON strip, the Warnings, the coverage preview and the coverage window.
- **Recompute.** One refresh of every result surface from the current form and the loaded image. Observable: each of the six result-surface widgets is updated once.
- **Text field.** A one-line text field of the CRC Designer: Width, Polynomial, Init, XOR out, Check, Name, Aliases, Address, Bytes, Ranges, Pad byte, Vector, Load path.
- **Toggle or dropdown.** Reflection in, Reflection out, Preset, Intra gap, Join gaps, On conflict, Store endianness, Mode.
- **Loaded image changes.** The session's loaded image (S5 CTX-FILES; the app's `current_file`) is set, replaced or cleared: a load, a project load, an unload. A byte change made in place (the apply of a change document) is not an image change here (`E1-rulings.md` §1, out of scope).
- **Pending change.** An operator edit of a text field, or a change of the loaded image, made after the system last recomputed.
- **Quiet time.** 150 ms.
- **Edit burst.** Two or more operator edits of text fields, each less than the quiet time after the one before, with no toggle or dropdown change, no preset pick and no template load between them.
- **Demo image.** The shipped 10 MB demo case (`examples/case_08_release_demo/README.txt`): `tools/synth/make_release_case.py` with seed 20260001 and size 10 MB. Its image has four ranges: boot `0x00000000`+`0x10000`, app `0x00040000`+`0x2C9FA0`, cal `0x00800000`+`0x131FC0`, config `0x00C00000`+`0x1000`. (Tests build it with `compute_region_sizes(10)` and `build_objects(regions, random.Random(20260001))`, the first two steps of `generate`; the bytes are those of `firmware.s19`.)
- **F-23 CRC scene.** The demo image is loaded; the CRC Designer is shown with the form it first shows (CRC-32/ISO-HDLC, Join gaps concat, Intra gap skip, Pad byte `0xFF`, On conflict abort); Ranges holds `0x00800000-0x00931FBF, 0x00C00000-0x00C00FFF` (guide ch12.4); no change is pending.
- **F-23 template.** A template file whose algorithm differs from the first-shown form in every algorithm field: CRC-16/MODBUS parameters with Check `0x4B37`, Name `demo-modbus`, Aliases `a, b`.
- **F-23 Split/Join scene.** The demo image is loaded; Split / Join / Export is open on `ranges(4)`; `range_00` and `range_02` are ticked; mode join, gaps concat, pad byte 0x00, format S19 (guide ch14.5–14.6). `range_01` (the app region, unticked) lies in the join gap.
- **Base reference.** The functions `_sweep` and `_conflict_marks` of `s19_app/tui/segment_split_view.py` at `b7b77c4`, copied verbatim into a test-support module as the oracle of the band's invariance.
