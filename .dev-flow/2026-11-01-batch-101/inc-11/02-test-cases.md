One case per coverage item `<requirement id>/<n>` of `01-requirements.md`, plus the acceptance cases `AT-I11-<n>` (black-box, through keys and dialogs). Written at E1, before any test: **Coverage** is `gap` where the test does not exist yet (E4 writes it), `partial` where an existing test asserts part of the expected result, and **Result** is `not_run` everywhere (no test was run at E1, operator rule).
