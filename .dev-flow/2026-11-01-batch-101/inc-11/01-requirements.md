## User stories

### US-I11-1 — a valid A2L raises no "unrecognized block" (F-02, D3-12)
As the operator, when I load an A2L that uses the blocks of ASAM MCD-2 MC (MOD_PAR, MOD_COMMON, AXIS_DESCR, REF_CHARACTERISTIC …) and keeps interface data inside IF_DATA, I want no `A2L_UNRECOGNIZED_BLOCK` issue for them, and a block the standard does not have to stay a warning, so that the Issues list holds real findings only and no note about an internal triage.

### US-I11-2 — the Issues screen shows each issue under its own severity, errors first (F-03, F-39)
As the operator, I want the Warnings filter to list only warnings, each issue to show under its own severity, and the list to run errors, then warnings, then info across all pages, so that the Issues screen agrees with its legend.

### US-I11-3 — a CURVE without axis points says so once (F-21)
As the operator, when the description window shows a CURVE whose axis points cannot be read, I want one line that says x is the point index, not the same note on every row, so that the point table stays readable.

### US-I11-4 — every MEMORY_SEGMENT that states a base and a size is read (F-29)
As the operator, I want the system to read a MEMORY_SEGMENT's name, base and size whether they sit on the `/begin` line, on the line after the long identifier, or on one line with the name, so that the Split / Join `a2l(<n>)` source and each tag's memory region are right.

## Definitions (terms only; additions to S2 CTX-A2L and S3 CTX-ISSUE)

- **ASAM block name** (S2, new list CTX-A2L-BLOCKS). The names that open a `/begin` block in ASAM MCD-2 MC 1.7: A2ML, ANNOTATION, ANNOTATION_TEXT, AR_COMPONENT, AXIS_DESCR, AXIS_PTS, BIT_OPERATION, BLOB, CALIBRATION_HANDLE, CALIBRATION_METHOD, CHARACTERISTIC, COMPU_METHOD, COMPU_TAB, COMPU_VTAB, COMPU_VTAB_RANGE, DEF_CHARACTERISTIC, DEPENDENT_CHARACTERISTIC, FIX_AXIS_PAR_LIST, FORMULA, FRAME, FUNCTION, FUNCTION_LIST, GROUP, HEADER, IF_DATA, IN_MEASUREMENT, INSTANCE, LOC_MEASUREMENT, MAP_LIST, MEASUREMENT, MEMORY_LAYOUT, MEMORY_SEGMENT, MOD_COMMON, MOD_PAR, MODULE, OUT_MEASUREMENT, OVERWRITE, PROJECT, RECORD_LAYOUT, REF_CHARACTERISTIC, REF_GROUP, REF_MEASUREMENT, STRUCTURE_COMPONENT, SUB_FUNCTION, SUB_GROUP, TRANSFORMER, TRANSFORMER_IN_OBJECTS, TRANSFORMER_OUT_OBJECTS, TYPEDEF_AXIS, TYPEDEF_BLOB, TYPEDEF_CHARACTERISTIC, TYPEDEF_MEASUREMENT, TYPEDEF_STRUCTURE, UNIT, USER_RIGHTS, VAR_ADDRESS, VAR_CHARACTERISTIC, VAR_CRITERION, VAR_FORBIDDEN_COMB, VARIANT_CODING, VIRTUAL, VIRTUAL_CHARACTERISTIC (62 names). The list's source and its check are in `E1-rulings.md` D-9 (checked at E3 against the public `a2lfile` grammar, which covers ASAM MCD-2 MC 1.5.0 … 1.7.1: its 62 `/begin` blocks, `AR_COMPONENT` added at E3).
- **Section name** (S3). The word after `/begin`, compared and reported in upper case; `<NAME>` in the message of R-VAL-032.1 is this upper-case name.
- **Inside an IF_DATA block** (S3). A section with an IF_DATA section among its enclosing sections, at any depth, inside IF_DATA as the section tree nests it (the parser's `/begin` / `/end` nesting: a one-line `/begin IF_DATA … /end IF_DATA` stays open in that tree, `E1-rulings.md` O-5). The IF_DATA section itself is not inside.
- **Severity rank** (S3). ERROR, then WARNING, then INFO; a severity other than these three (OK, NEUTRAL) ranks after INFO.
- **Record words** (S2, CTX-A2L). Of a MEMORY_SEGMENT block: the words of its `/begin` line after `/begin MEMORY_SEGMENT`, then the words of each of its own lines (never a line of a nested block), in file order. A quoted text is one word, without its quotes, and is a quoted word (`""` is the empty quoted word); a `"` left open ends its quoted text at the end of its line (the quote state starts closed on each line). Outside a quoted text, a comment (`/* … */`, which may span lines, or `//` to the end of the line) gives no word.
- **Number** (S2, word). An unquoted word that matches, in ASCII only, an optional sign `+` or `-` followed by either 1 to 10 decimal digits `0`-`9` (leading zeros allowed: `0400` is 400) or `0x` / `0X` and 1 to 8 hex digits `0`-`9`, `A`-`F`, `a`-`f`; its value is that signed decimal or hex integer (`0x16000`, `4096`, `-1`). No other word is a Number: not a quoted word, not a word with `_`, not a `0o` / `0b` word, not a word with a non-ASCII digit, not a longer digit run.
- **Address word** (S2). Of a MEMORY_SEGMENT block: the first record word after the name that is not a quoted word and starts with an ASCII digit, `+` or `-`.
- **Program-type word** (S2). CALIBRATION_VARIABLES, CODE, DATA, EXCLUDE_FROM_FLASH, OFFLINE_DATA, RESERVED, SERAM, VARIABLES.
- **Memory-type word** (S2). EEPROM, EPROM, FLASH, NOT_IN_ECU, RAM, REGISTER, ROM.
- **Program type / memory type** (S2). The segment's usage and kind; the memory region of CTX-A2L reads them ("RAM or VARIABLE segments are ram; FLASH, ROM or CODE are flash").
- **Axis value** (S2, description window). A point of a CURVE's point table has an axis value when the CURVE's axis points were read for the point's position.
- **Point-table rows** (S2). The lines of the description window from the table header `x   y` to the last point line; each carries the table's two-space indent.
