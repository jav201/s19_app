s19tui — one set per screen, upgrades layered by effort tier (prototype v2)

What changed since v1 (your feedback): every screen keeps its CURRENT layout skeleton — same rail, same command bar, same panes in the same places. Tiers only enrich the visual data-insight cues, cumulatively: EASY = colors/markup/border-titles only → MID = + micro-visuals inside existing panes → BIG = + one structural addition within the same screen. Styling follows the dolphie idiom (muted labels / bright values, soft pastel semantics, navy depth stack, humanized numbers).

Images are fixed-size (not stretched) — click any to open the full SVG. Run live: python prototypes/screen_upgrades.prototype.py — keys 1–5 screen, [ ] tier, q quit.

About the “big font” you've been seeing: dolphie's screenshots are simply a maximized terminal (~240×80 cells) at ~11pt font; its layouts are calibrated for that canvas. s19tui's layouts cap at ~120 cols, so at common font sizes the same content looks zoomed. Each BIG tier below is also exported at 160×42 to show how the denser style pays off as the terminal grows. (Recommendation: run maximized with font 10–12; a batch item can raise the layout caps past 120 cols.)
