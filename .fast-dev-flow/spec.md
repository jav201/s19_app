## 1. Objective (1 line)

Regenerate the 19 stale `test_tc016s_density_layout_snapshot` SVG baselines — stale since batch-58 added the CRC Designer rail entry — in the canonical CI environment, so the advisory `snapshot` job returns to green and stops masking genuine future drift.

## 2. User stories

## 4. Validation strategy

No new tests are written — this batch changes only test *fixtures*, and the existing 29 `test_tc016s_density_layout_snapshot` cells **are** the acceptance suite. Evidence chain: (a) a locally-measured pre-regen baseline run recorded before any file changes (the counterfactual — 19 RED); (b) the CI `snapshot-regen.yml` run's own "changed baselines" log, read from that run; (c) the four post-apply checks AC-1..AC-4 run locally; (d) one complete `-m "not slow"` run for AC-5, with the count read from that single run's own output (C-19: never stitched across partial runs). Local rendering is trusted for *verification* only — local `textual==8.2.8` equals the CI pin and reproduces the documented 19-cell failure set exactly — but local `--snapshot-update` is **forbidden** for *generation* (local Python 3.14 vs canonical 3.11; `reference_snapshot_regen_env`).

Recorded as a logged decision rather than escalated to a `security-reviewer` pass, which would be disproportionate for 19 SVG fixtures.
